# OpenShorts dashboard

React 18, Vite and Tailwind frontend for OpenShorts. Setup, configuration and
the API token are described in the [main README](../README.md).

```bash
npm ci
npm run dev     # Vite dev server; proxies /api, /videos, /thumbnails, /gallery and /video to the backend
npm run lint    # ESLint, zero warnings allowed
npm run build   # production build into dist/
```
